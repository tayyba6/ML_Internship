## Featured Project: Content Review Prioritization

### Problem

**Which pages should be reviewed first for possible content improvement, using signals available before the review decision?**

The goal is not to predict Google's ranking algorithm or automatically change website content.

Instead, I treated machine learning as a **decision-support tool**: when review capacity is limited, which pages should a human reviewer examine first?

### Approach

I built an end-to-end Python/ML workflow:

```text
Search performance data
        ↓
Data validation & feature framing
        ↓
Signal audit & leakage checks
        ↓
Transparent ranking baseline
        ↓
Interpretable Decision Tree
        ↓
Client-grouped evaluation
        ↓
Error analysis & robustness checks
        ↓
Ranked content-review queue
